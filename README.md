# 2D-C-Gravity-Simulator
A simple implementation of the planets gravity system inspierd by a youtube video I saw.

The simulation uses the SDL2 framework for the graphics.

## Compilation 

To compile it: 

```
g++ main.cpp  object.cpp -w -lSDL2
```


And to run it:
```
./a.out
```
